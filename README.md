# Pre-entrega - Gestión de Productos comisión #26225
Trabajo práctico del curso Back End Node.js - Talento Tech.
Se consume la FakeStore API para gestionar productos.

## Requisitos
Node.js 18 o superior (necesario para `fetch` nativo)

## Comandos
- `npm run start GET products`
- `npm run start GET products/15`
- `npm run start POST products T-Shirt-Rex 300 remeras`
- `npm run start DELETE products/7`

## Instalación
npm install
